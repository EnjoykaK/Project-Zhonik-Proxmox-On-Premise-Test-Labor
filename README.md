# Project Zhonik | Proxmox On-Premise-Test-Labor

> **Projektarbeit (Fachinformatiker für Systemintegration)**  
> **Thema:** Konzeption und Implementierung einer isolierten Entwicklungs- und Monitoring-Umgebung auf Basis von Proxmox VE.



## Über das Projekt

Ein schlüsselfertiges On-Premise-Labor zur Bereitstellung von isolierten Diensten (Docker-LXC, PostgreSQL, Prometheus/Grafana) auf einem Proxmox VE Hypervisor.

### Ziele des Projekts
- **Isolierung:** Sichere Netztrennung zwischen Testumgebung und Produktivnetz.
- **Effizienz:** Ressourcen-schonende Bereitstellung von LXC-Containern und VMs.
- **Observability:** Zentrales Monitoring der Infrastruktur und Metriken mit Prometheus und Grafana.
